# 验收确认单

## 适用场景
用于提测后到上线前，对需求的测试结果、业务验收结果、遗留问题和上线建议进行统一确认，保证“测试通过”和“业务认可”同时成立。

## 填写原则
- 测试结论和业务验收结论必须分别填写。
- 遗留问题要明确是否阻塞上线。
- 上线建议必须清晰，不使用模糊表述。
