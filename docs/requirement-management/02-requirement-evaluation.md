# 需求评估单

## 适用场景
用于需求澄清完成后，对业务价值、优先级、复杂度、风险、依赖和排期建议进行统一评估，支撑是否立项、何时排期和做多大范围。

## 填写原则
- 业务价值、实现成本、风险项都要落到具体场景，不写空泛结论。
- 优先给出最小可行方案，再讨论完整方案。
- 结论必须明确：做、暂缓、拒绝，三选一。
- 在“人负责登记，AI 负责评估/排期”的模式下，本单默认由 AI 生成并作为正式记录保存。
- 工作量优先描述为复杂度、改动范围、不确定性和验证负担；如需时间预估，应标注为`AI 估算`。
- 当信息不足时，应先列出待澄清问题，再给出阶段性结论。
