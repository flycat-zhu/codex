# 需求交接单

## 适用场景
用于需求正式进入执行阶段时，由需求管理、开发、测试和产品共同确认范围、规则、验收标准与责任边界，作为多角色对齐的基准文档。

## 填写原则
- 本次要做和本次不做必须同时写清楚。
- 验收标准必须是可验证、可测试、可判断的描述。
- 所有变更都应在此文档或其补充版本中留痕。
